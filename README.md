# Full Stack College Portal System

A full-stack web application developed using **Spring Boot**,
**MySQL**, and **JavaScript** to manage student and institutional
records efficiently through a simple, responsive web interface.

## Features

- Register and manage student records with full CRUD operations
  (Create, Read, Update, Delete)
- Handle institutional application/registration workflows with
  file upload support (e.g., document submission)
- View, search, and delete records through dynamic web pages
- RESTful API architecture for backend-frontend communication
- Real-time data rendering using Fetch API
- MySQL database integration with Spring Data JPA

## Tech Stack

- **Backend:** Java, Spring Boot, Spring Data JPA
- **Database:** MySQL
- **Frontend:** HTML, CSS, JavaScript
- **Build Tool:** Maven
- **IDE:** IntelliJ IDEA

## How to Run

1. Clone the repository
```bash
   git clone https://github.com/yourusername/fullstack-college-portal-system.git
```
2. Configure your MySQL database in `application.properties`
3. Run the application via `CollegeportalApplication.java`
4. Open `http://localhost:8080/index.html` in your browser
